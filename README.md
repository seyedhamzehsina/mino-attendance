# سامانه مدیریت حضور کارکنان مینو

یک سامانهٔ تک‌فایلی و راست‌به‌چپ برای ثبت، مشاهده و تحلیل حضور و غیاب کارکنان با تقویم شمسی.

## امکانات

- ثبت ساعت ورود و خروج و محاسبهٔ کارکرد، تأخیر، کم‌کاری و اضافه‌کاری
- نمایش همهٔ کارکنان در هر روز؛ نبودِ رکورد در روز کاری با برچسب «عدم حضور» مشخص می‌شود
- تشخیص پنج‌شنبه، جمعه و تعطیلات رسمی تعریف‌شده؛ حضور در تعطیلی با وضعیت «تعطیل‌کاری» نمایش داده می‌شود
- صفحهٔ جزئیات هر کارمند با شمارش عدم حضورها و تعطیل‌کاری‌ها
- ورود گروهی فایل‌های Excel و پشتیبانی از نام‌های معادلِ ستون‌ها
- تهیه و بازیابی نسخهٔ پشتیبان و نگهداری داده‌ها در مرورگر (Local Storage)
- دادهٔ نمونه برای چهار کارمند در بازهٔ ۱ تا ۳۰ شهریور ۱۴۰۵، شامل همهٔ حالت‌های عادی، اضافه‌کاری، کم‌کاری، عدم حضور و تعطیل‌کاری

## اجرا

این پروژه به نصب وابستگی نیاز ندارد. فایل `index.html` را در مرورگر باز کنید.

برای مشاهدهٔ سریع همهٔ جریان‌ها، در بخش ابزارها روی «داده نمونه 4 نفر (شهریور)» بزنید. این کار داده‌های فعلی مرورگر را با دادهٔ آزمایشی جایگزین می‌کند.

## ستون‌های قابل خواندن از Excel

سامانه عنوان‌های فارسی و انگلیسیِ رایج را می‌پذیرد. حداقل نام کارمند و تاریخ لازم است؛ ساعت ورود و خروج برای محاسبهٔ کارکرد استفاده می‌شوند.

| مفهوم | عنوان‌های پذیرفته‌شده (نمونه) |
| --- | --- |
| نام کارمند | `نام و نام خانوادگی`، `نام کارمند`، `نام`، `Employee Name`، `Employee`، `Full Name`، `Name` |
| تاریخ | `تاریخ`، `تاریخ ورود`، `روز`، `Date`، `Work Date` |
| ساعت ورود | `ساعت ورود`، `ورود`، `زمان ورود`، `شروع کار`، `In`، `Check In`، `Start Time` |
| ساعت خروج | `ساعت خروج`، `خروج`، `زمان خروج`، `پایان کار`، `Out`، `Check Out`، `End Time` |
| شناسه (اختیاری) | `کد پرسنلی`، `شماره پرسنلی`، `کد کارمند`، `Personnel Code`، `Employee ID`، `ID` |
| واحد (اختیاری) | `واحد`، `بخش`، `دپارتمان`، `Department`، `Unit` |

## نگهداری داده

داده‌ها فقط در مرورگر دستگاه شما ذخیره می‌شوند. پیش از پاک‌سازی مرورگر یا جابه‌جایی دستگاه، از گزینهٔ «تهیه نسخه پشتیبان» استفاده کنید. فایل پشتیبان را می‌توان از همان بخش بازگردانی کرد.

## نکتهٔ تقویمی

تعطیلات رسمی نمونه برای سال ۱۴۰۵ در کد تعریف شده‌اند. برای استفاده در سال‌های دیگر، فهرست تعطیلات رسمی را در فایل `index.html` به‌روزرسانی کنید.
